# RemoteDesk Claude Agent Plugin

The RemoteDesk Claude Agent host bridge preview uses the pinned Claude Agent SDK for sessions, streaming turns, cancellation, approvals, questions, attachments, history, fork/rename and the shared mTLS RemoteDesk protocol. It authenticates with an Anthropic API key only; claude.ai login is never offered or used (see the Agent SDK terms). App exposure and parity claims remain gated until real API key, approval, restart/recovery and HarmonyOS client acceptance is complete.

Claude Code CLI **2.1.286** and Claude Agent SDK **0.3.286** are the only accepted versions in this package. See [README.md](README.md) for key setup and commands.
