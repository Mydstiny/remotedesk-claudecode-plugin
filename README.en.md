# RemoteDesk Claude Code Plugin

The RemoteDesk Claude Code host bridge preview uses the pinned Claude Agent SDK for sessions, streaming turns, cancellation, approvals, questions, attachments, history, fork/rename and the shared mTLS RemoteDesk protocol. App exposure and parity claims remain gated until real account, approval, restart/recovery and HarmonyOS client acceptance is complete.

Claude Code **2.1.286** and Claude Agent SDK **0.3.286** are the only accepted versions in this package.
