# Roadmap

1. Pin and fixture the Claude Code stream-json contract without model calls in tests.
2. Implement a host-only adapter behind the `UNVERIFIED_CLAUDE_PROTOCOL` gate.
3. Add the shared RemoteDesk mTLS bridge, project state, QR/link pairing and control panel only after the adapter passes lifecycle and security review.
4. Add the HarmonyOS backend after the host bridge and client protocol are independently accepted.
